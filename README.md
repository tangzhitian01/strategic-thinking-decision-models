# Strategic Thinking & Decision Models

这是从《150个思维模型&麦肯锡战略思维分析工具》整理出的战略思维与决策 Skill。

## 内容

- `skill/SKILL.md`: 可安装的 Codex Skill 入口
- `skill/references/model-catalog.md`: 150 个模型的描述和用法
- `skill/references/capabilities/`: 6 个战略能力模块
- `source/README.md`: 原始 PDF 说明和校验信息

## 安装

将 `skill/` 目录复制到 Codex 技能目录，并确保入口文件为 `skill/SKILL.md`。
