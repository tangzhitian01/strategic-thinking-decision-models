# 150 个思维模型：描述与用法

来源：`D:\夸克网盘\150个思维模型&麦肯锡战略思维分析工具.pdf`

## 总数

共 **150 个模型**，分为 7 个部分：

- 学习力：20 个
- 思考力：48 个
- 创造力：25 个
- 设计力与行动力：28 个
- 沟通力与共情力：9 个
- 故事力：6 个
- 领导力：14 个

## Part 01 学习力（20）

| # | 模型 | 描述 | 用法 |
|---:|---|---|---|
| 1 | 高效复盘模型 | 回顾经历、评估结果、分析原因、提炼规律并迭代。 | 项目结束后按“情景—任务—行动—结果—改进”复盘。 |
| 2 | 费曼学习法 | 通过输出、简化和反馈检验是否真正理解。 | 用自己的话教给外行，记录卡点，再回到原文补缺。 |
| 3 | 刻意练习 | 在略高于当前能力的学习区内，专注重复并获取反馈。 | 把技能拆成小动作，逐项练习、纠错、再测。 |
| 4 | 认知天性 | 学习依赖主动提取、间隔复习和情境连接，而非反复阅读。 | 合上材料回忆、做测试、间隔复习并联系旧知识。 |
| 5 | 学习金字塔 | 主动实践和教授他人的保持效果通常高于被动听读。 | 读完后实践、讨论并输出成果，不停留在划线摘抄。 |
| 6 | PDCA 原则 | 计划、执行、检查、处理改进的循环。 | 为目标建立计划，执行后检查偏差，把经验标准化。 |
| 7 | 经验积累型学习 | 在相对稳定环境中通过试错、反馈和总结形成经验。 | 重复实践同类任务，把有效做法沉淀为流程。 |
| 8 | 深度思考型学习 | 从现象洞察本质，匹配规律并跨场景迁移。 | 遇到新问题先找底层规律，再迁移已有模型。 |
| 9 | OODA 模型 | Observe、Orient、Decide、Act，即观察、定位、决策、行动。 | 用于快速变化环境，行动后立即重新观察。 |
| 10 | RIA 阅读法 | Reading、Interpretation、Appropriation：阅读、解释、吸收应用。 | 读一段，用自己的话解释，再联系经验并设计应用。 |
| 11 | 心流模型 | 目标清晰、挑战与能力匹配、专注投入并获得即时反馈。 | 调整任务难度、减少干扰、设置短周期反馈。 |
| 12 | 四域空间生存法则 | 用舒适区、学习区、恐慌区等边界理解成长和风险。 | 选择略有挑战但不至于失控的学习区。 |
| 13 | 个人成长曲线 | 能力成长通常经历启动、加速、平台期和衰退/转型。 | 发现平台期时换方法、换场景或进入新曲线。 |
| 14 | 双目标清单系统 | 同时管理结果目标和过程/行为目标。 | 为每个结果目标配套可每天执行的行为清单。 |
| 15 | 自我反馈模型 | 通过目标、行动、结果和反馈不断修正自我表现。 | 预先写成功标准，事后对照实际结果和偏差。 |
| 16 | 个人表现模型/橡皮筋模型 | 表现由目标拉力、能力基础和现实约束共同决定。 | 找出目标与能力的差距，针对最关键的拉力补能力。 |
| 17 | 瑞士奶酪理论 | 事故通常是多层防线同时出现缺口的结果。 | 给关键流程设置多层检查、冗余和责任隔离。 |
| 18 | 十字路口模型 | 面对多个方向时，通过比较道路、代价、机会和回头路做选择。 | 列出继续、转向、暂停、回退等选项和长期代价。 |
| 19 | 个人潜力陷阱 | 过度追逐“潜力”可能忽视现实能力、资源和执行约束。 | 区分真实成果与想象潜力，优先验证可交付结果。 |
| 20 | 双重回路学习模型 | 不只修正行动，还反思目标、规则和背后的假设。 | 结果不好时同时问“做错了什么”和“目标/规则是否错了”。 |

## Part 02 思考力（48）

| # | 模型 | 描述 | 用法 |
|---:|---|---|---|
| 21 | 多元思维模型 | 用多个学科和视角共同解释同一问题。 | 先列经济、心理、技术、组织等视角，再交叉验证。 |
| 22 | 第一性原理 | 把问题还原到不可再分的基本事实和约束。 | 区分事实、假设和惯例，从底层重新构造方案。 |
| 23 | 探月思维 | 像探月一样分阶段接近目标，先探测再投入。 | 将大目标拆成低成本试探、验证和逐步加码。 |
| 24 | 复利思维 | 小的持续积累会产生非线性长期结果。 | 优先投资可重复、可积累、可产生滚雪球效应的行动。 |
| 25 | 能力圈 | 明确自己真正理解和能判断的领域边界。 | 只在能力圈内重仓；圈外先学习、请教或降低风险。 |
| 26 | 路径依赖 | 过去的选择会通过成本、习惯和制度限制未来路径。 | 识别“因为过去这样做所以继续”的锁定，评估切换成本。 |
| 27 | 势能差 | 差异、落差或积累的势能会推动系统变化。 | 找出资源、信息、能力或需求的落差，寻找转化机会。 |
| 28 | 能量模型 | 关注系统中资源、注意力、动机和行动能量的流入流出。 | 找出消耗最大的环节，减少漏损并把能量集中到关键目标。 |
| 29 | 大脑系统思维模型 | 用自动、情绪和理性等不同认知系统解释判断偏差。 | 重要决定先放慢，补数据、换视角并检查直觉误导。 |
| 30 | 五层次分析理论 | 从现象、行为、能力、信念价值观到身份/使命逐层追问。 | 判断问题到底是技能问题、规则问题还是身份和价值观问题。 |
| 31 | 理性“吃瓜”模型 | 面对热点和传闻时区分事实、观点、情绪和利益。 | 先确认来源和证据，再判断叙事者的动机与信息缺口。 |
| 32 | 查理·芒格人生自检清单 | 用心理偏差、概率、激励和反向思考检查判断。 | 决策前逐项问：激励是什么、概率多大、我可能错在哪里。 |
| 33 | 人生算法 | 将价值观和经验转成可重复执行的决策规则。 | 为高频问题写默认规则，减少临场消耗并定期更新。 |
| 34 | 九屏幕分析思维 | 从过去/现在/未来和系统/子系统/超系统九个格子观察对象。 | 设计产品或战略时同时看历史、当前、趋势及上下游影响。 |
| 35 | 整合思维 | 同时容纳冲突观点，寻找比二选一更好的第三方案。 | 分别写出两种观点的有效部分，再重构共同方案。 |
| 36 | 系统思维 | 关注变量、因果链、反馈回路、滞后和系统整体。 | 画因果图，区分增强回路与调节回路，避免只改表面变量。 |
| 37 | 杠杆思维 | 用少量关键资源撬动更大结果。 | 找到代码、媒体、资本、流程、伙伴或制度等高杠杆点。 |
| 38 | 生态思维 | 把组织放进客户、伙伴、竞争者、平台和环境组成的生态中。 | 分析共生、竞争、依赖和资源流动，不只盯着单个企业。 |
| 39 | 奥卡姆剃刀 | 在解释力相近时优先选择更简单、假设更少的解释。 | 删除不必要变量，但不能为了简单而忽略关键证据。 |
| 40 | 反脆弱思维模型 | 某些系统能从波动、压力和试错中变得更强。 | 采用小额多次试验、可控损失和收益不对称的方案。 |
| 41 | 黄金圈思维模型 | 从 Why、How、What 依次回答为什么、如何做、做什么。 | 先明确使命和价值，再设计方法和具体产品。 |
| 42 | 熵增定律 | 封闭系统趋向混乱，需要持续输入能量和秩序。 | 定期整理信息、流程、环境和责任，防止组织失控。 |
| 43 | 冗余备份系统 | 用备份、冗余和替代路径提高系统韧性。 | 为数据、供应商、关键岗位和应急流程设计替代方案。 |
| 44 | 断裂点理论 | 系统在累积压力或关键条件变化后可能突然跃迁。 | 识别阈值、临界信号和不可逆变化，提前准备转向。 |
| 45 | 指数对数思维模型 | 有些增长呈指数，有些感知和收益呈对数递减。 | 区分线性直觉与非线性规律，判断规模、增长和边际收益。 |
| 46 | 多棱镜思维 | 同一对象从多个学科、时间和利益相关者视角观察。 | 要求至少提出三种解释或视角，再形成综合判断。 |
| 47 | 黑匣子思维模型 | 不责备地记录失败、分析原因并改进系统。 | 保存数据和决策记录，做事后复盘而不是只追责个人。 |
| 48 | 归纳法与演绎法 | 归纳从个别事实形成一般规律，演绎从规律推出个案结论。 | 先用数据归纳假设，再用具体案例检验推论。 |
| 49 | 矩阵思维 | 用两个或多个维度把对象放入象限或组合格。 | 选择关键维度，放入选项，观察优先级、风险和空白区域。 |
| 50 | 5W2H 问题分析法 | 从 What、Why、Where、When、Who、How、How much 全面提问。 | 制定项目计划、责任表、预算和执行条件。 |
| 51 | 5Why 思考法 | 连续追问“为什么”寻找可干预的根因。 | 从问题表象向下追问，直到找到能改变行动的原因。 |
| 52 | 5So 思考法 | 连续追问“所以呢”推演事件的后果链。 | 评估一个决策对客户、财务、组织和长期战略的连锁影响。 |
| 53 | 10/10/10 法则 | 分别考虑 10 分钟、10 个月和 10 年后的感受与结果。 | 处理短期情绪强、长期影响大的重大选择。 |
| 54 | 思维导图 | 以中心主题向外展开层级和关联。 | 梳理问题、书籍、活动或方案的要素和联系。 |
| 55 | SWOT 分析 | 从内部优势/劣势和外部机会/威胁形成策略组合。 | 写出 SO、ST、WO、WT 行动，不停留在四象限罗列。 |
| 56 | MECE 分析法 | Mutually Exclusive、Collectively Exhaustive，即相互独立、完全穷尽。 | 搭问题树和分类表，减少重复与遗漏。 |
| 57 | 流程图 | 用节点和箭头表示步骤、判断、责任和流转。 | 画现状流程，找瓶颈、返工点、等待点和自动化机会。 |
| 58 | 差距分析 | 比较现状与目标状态，识别能力、资源和结果差距。 | 列出目标、现状、差距、原因、行动和完成指标。 |
| 59 | 空—雨—伞 | 从事实现象推导判断，再形成行动建议。 | 先陈述数据，再解释含义，最后提出明确建议。 |
| 60 | 逻辑树 | 将总问题拆成相互关联的子问题和假设。 | 从目标向下拆结果树、原因树或方案树。 |
| 61 | 假设思考 | 先提出可证伪的解释，再用最小成本验证。 | 写假设、证据、验证方法、通过标准和后续行动。 |
| 62 | 波特的 3 个基本战略 | 成本领先、差异化和集中/聚焦三种竞争方式。 | 明确企业靠低成本、独特价值还是细分市场取胜。 |
| 63 | 帕累托法则 | 少数关键因素往往贡献大部分结果。 | 找出贡献最大的客户、产品、问题或行动，优先投入。 |
| 64 | 价值链分析 | 把企业活动拆成主要活动和支持活动，寻找价值与成本来源。 | 分析采购、生产、销售、服务等环节的优势和瓶颈。 |
| 65 | 波士顿矩阵 | 以市场增长率和相对市场份额划分明星、问题、金牛、瘦狗。 | 决定业务是加大投资、维持、试探还是退出。 |
| 66 | 安索夫矩阵 | 以产品和市场的新旧组合形成渗透、开发、开发产品和多元化。 | 选择增长路径，并比较各路径的不确定性和资源要求。 |
| 67 | 隐含前提思维模型 | 检查结论背后未说出的条件和假设。 | 问“这个结论成立必须满足什么”，逐项验证关键前提。 |
| 68 | 反作用力思维模型 | 预测行动会诱发的对手反应、用户适应和系统反弹。 | 做方案评估时写出二阶、三阶后果和应对措施。 |

## Part 03 创造力（25）

| # | 模型 | 描述 | 用法 |
|---:|---|---|---|
| 69 | 六顶帽思维 | 用白、红、黑、黄、绿、蓝六种角色分离事实、情绪、风险、价值、创意和流程。 | 团队讨论时按帽子轮流发言，避免事实和情绪混在一起。 |
| 70 | SCAMPER 创新思维 | Substitute、Combine、Adapt、Modify、Put to other use、Eliminate、Reverse。 | 对产品或流程逐项替换、组合、改造、删减和反转。 |
| 71 | 完型融合思维 | 将分散元素重新组合成完整结构或新意义。 | 观察不同领域的模块，寻找可以重新组合的功能和体验。 |
| 72 | 逆向思维 | 从相反目标、相反假设或失败结果倒推方案。 | 问“怎样一定会失败”，再把失败条件转成防范或创新方向。 |
| 73 | 类比思维 | 借用其他领域的结构、机制或经验解决当前问题。 | 找结构相似的行业、自然系统或产品，再迁移其机制。 |
| 74 | 头脑风暴 | 延迟评价，先大量生成想法，再集中筛选。 | 规定时间和数量，先发散后收敛，记录所有想法。 |
| 75 | KJ 法 | 将大量零散信息写成卡片、聚类并归纳主题。 | 访谈或调研后把语句贴卡，分组命名，再发现共性。 |
| 76 | 曼陀罗思考法 | 以中心主题向八个方向扩展，再继续细化。 | 用 3×3 九宫格扩展产品、问题、内容或行动选项。 |
| 77 | 利弊均衡表 | 把方案的收益、成本、风险和机会并列比较。 | 对每个选项分别列利弊，并标注权重和不可逆后果。 |
| 78 | 支付矩阵 | 在不同情境和结果下比较方案的收益/支付。 | 列出情境概率、方案结果和可能收益，识别风险暴露。 |
| 79 | 决策矩阵 | 用多个评价标准和权重对选项打分排序。 | 先确定标准和权重，再打分并做敏感性检查。 |
| 80 | 投资组合矩阵 | 按风险、收益、增长或资源维度管理多个项目组合。 | 让高风险、高潜力和稳定现金流项目形成平衡组合。 |
| 81 | 排列组合思维 | 通过排列、组合和重新配置扩展可能性空间。 | 改变人、产品、渠道、时间和资源的组合方式。 |
| 82 | 费马—帕斯卡系统 | 用概率、期望值和不确定性处理风险决策。 | 列出可能结果和概率，用期望收益而不是单一最好情景判断。 |
| 83 | 复杂自适应系统 | 多个主体相互作用，系统会自组织并产生不可预期结果。 | 做平台、组织和市场设计时关注反馈、适应和涌现。 |
| 84 | 规模错觉 | 规模、数量或视觉比例可能误导对重要性的判断。 | 把绝对量换成比例、基数、趋势和人均指标比较。 |
| 85 | 恐惧本能 | 人会高估威胁、低估进展并被危险信息吸引。 | 判断风险时看基准率、概率和实际暴露，不只看最坏新闻。 |
| 86 | 负面思维 | 过度聚焦损失、错误和坏消息会扭曲判断。 | 同时写风险、收益、已有资源和可控行动，防止只看坏处。 |
| 87 | 直线思维 | 把非线性、波动或反馈系统误认为按直线发展。 | 预测时检查拐点、边际收益、反馈回路和滞后效应。 |
| 88 | 单一视角思维本能 | 用一个角度解释所有问题，忽略其他变量。 | 强制列出不同利益相关者、时间尺度和学科视角。 |
| 89 | 命中注定思维本能 | 把现状和未来当作注定，忽视变化和行动。 | 问哪些变量可改变、哪些趋势可逆、现在能做什么实验。 |
| 90 | 以偏概全思维本能 | 从少量样本或个案推断整体。 | 检查样本量、代表性、基准率和反例。 |
| 91 | 一分为二思维本能 | 把连续谱简化成好/坏、赢/输、支持/反对。 | 寻找中间状态、概率分布、分阶段方案和第三选项。 |
| 92 | 归咎他人思维本能 | 将结果单纯归因于他人品格，而忽略系统和情境。 | 同时分析个人、流程、激励、资源和环境因素。 |
| 93 | 情急生乱思维本能 | 时间压力和情绪会降低信息处理和判断质量。 | 先稳定情绪，明确下一步最小行动，再补齐关键事实。 |

## Part 04 设计力与行动力（28）

| # | 模型 | 描述 | 用法 |
|---:|---|---|---|
| 94 | 马斯洛需求层次理论 | 需求可从生理、安全、归属、尊重到自我实现等层次观察。 | 分析产品或激励到底满足用户哪一层需求。 |
| 95 | NLP 思维逻辑层次 | 从环境、行为、能力、信念价值观、身份和使命逐层分析改变。 | 判断应该改环境、技能、信念还是身份定位。 |
| 96 | SMART 原则 | 目标应具体、可衡量、可达成、相关且有时限。 | 将“提升业绩”改写成有数字、期限和责任人的目标。 |
| 97 | 创业 Idea 估值模型 | 从市场、需求、团队、资源、竞争和商业化潜力评估想法。 | 给创意做多维评估，先验证需求和付费意愿。 |
| 98 | 护城河思维 | 关注难模仿、可持续的成本、品牌、网络、转换成本或规模优势。 | 判断优势能否保持，并持续投资于难复制能力。 |
| 99 | 设计思维 | 以用户为中心，经历共情、定义、创意、原型和测试。 | 先观察真实用户，再做低成本原型和快速迭代。 |
| 100 | 上瘾 HOOK 模型 | 触发、行动、可变奖励、投入形成循环。 | 设计产品留存机制，同时检查是否造成不健康依赖。 |
| 101 | RFM 客户价值分层 | 按最近购买、购买频率和购买金额判断客户价值。 | 将客户分层，分别设计留存、复购、激活和召回策略。 |
| 102 | AARRR 漏斗模型 | Acquisition、Activation、Retention、Revenue、Referral。 | 按获客、激活、留存、收入、推荐定位增长瓶颈。 |
| 103 | 营销 4P 理论 | Product、Price、Place、Promotion，即产品、价格、渠道、促销。 | 检查营销组合是否共同支持目标市场和定位。 |
| 104 | 需求三角 | 需求由缺乏感、目标感和消费者能力共同形成。 | 判断用户是否痛、是否想要结果、是否有能力采取行动。 |
| 105 | MVP | 用最小可行产品验证关键假设，而非一次做完整产品。 | 只开发验证需求、价值和付费的最小功能集合。 |
| 106 | 峰终定律 | 用户对体验的记忆主要受高峰和结尾影响。 | 设计服务体验时重点优化关键高峰和结束环节。 |
| 107 | 人生断舍离 | 通过舍弃、整理和脱离减少不必要的人事物。 | 定期删除低价值承诺、物品、信息和关系负担。 |
| 108 | 3C 分析 | 从 Customer、Competitor、Corporation 看客户、竞争者和企业自身。 | 做战略定位时同步分析需求、竞争和资源能力。 |
| 109 | STP 分析 | Segmentation、Targeting、Positioning，即细分、目标市场、定位。 | 选择最有吸引力且自身能服务的细分市场，形成定位。 |
| 110 | 用户画像分析 | 用人口、行为、兴趣、需求和价值数据描述典型用户。 | 为产品、广告、推荐和服务设计建立可操作的用户标签。 |
| 111 | 消费者旅程 | 描述用户从认知、考虑、购买、使用到分享的全过程。 | 找出每个接触点的目标、情绪、摩擦和机会。 |
| 112 | 市场营销组合 | 将产品、价格、渠道、促销等可控变量组合以服务目标市场。 | 检查各营销动作是否一致地创造客户价值。 |
| 113 | 核心竞争力分析 | 寻找有价值、稀缺、难模仿且不可替代的资源和能力。 | 将资源能力与客户价值、组织整合和竞争差异连接。 |
| 114 | 五力分析模型 | 分析供应商、买家、新进入者、替代品和现有竞争者的压力。 | 判断行业利润空间、进入壁垒和竞争策略。 |
| 115 | AIDMA 模型 | Attention、Interest、Desire、Memory、Action，即注意、兴趣、欲望、记忆、行动。 | 设计广告和营销内容的消费者心理路径。 |
| 116 | PEST 分析模型 | 从政治、经济、社会和技术分析宏观环境。 | 做市场进入、战略规划和趋势扫描。 |
| 117 | 产品生命周期 | 产品经历导入、成长、成熟和衰退阶段。 | 根据阶段调整研发、定价、渠道、促销和资源投入。 |
| 118 | 品牌资产 | 品牌知名度、联想、感知质量和忠诚度形成品牌价值。 | 评估品牌是否能带来溢价、选择和复购。 |
| 119 | 市场缺口模型 | 在现有供给和用户需求之间寻找未被满足的空间。 | 比较细分人群、需求强度、竞争供给和进入难度。 |
| 120 | 长尾模型 | 少量热门产品之外，大量小众产品合计也可形成大市场。 | 用数字化、低库存和平台分发服务小众需求。 |
| 121 | 断层—扩散模型 | 新产品从创新者经由早期用户向大众市场扩散，中间存在鸿沟。 | 分阶段设计产品、证据和传播，避免直接从小众跳大众。 |

## Part 05 沟通力与共情力（9）

| # | 模型 | 描述 | 用法 |

| 122 | 情绪 ABC 理论 | 事件 A 不直接决定情绪 C，信念/解释 B 才是关键中介。 | 记录事件、自动想法和情绪行为，再重写解释。 |
| 123 | 认知重建 | 识别不合理或极端想法，用更符合证据的解释替代。 | 为负面判断寻找证据、反证和更平衡的表述。 |
| 124 | 高效倾听模型 | 通过专注、澄清、复述、共情和确认理解对方。 | 少打断，多复述对方观点和需求，再确认是否准确。 |
| 125 | 化解冲突模型 | 从立场转向利益和真实需求，寻找双赢方案。 | 分别陈述双方主张，追问深层需求，再共同生成方案。 |
| 126 | 冰山模型 | 可见行为之下还有情绪、需求、价值观和经历。 | 冲突时不要只处理表面行为，继续探索隐含需求。 |

| 128 | 六大圈层模型 | 从个人、家庭、组织、社会等关系圈层理解互动和影响。 | 判断问题影响了哪些圈层，明确沟通对象和边界。 |
| 129 | 社会氛围和布尔迪厄模型 | 关注场域、资本、惯习和社会关系对行为的影响。 | 分析一个人的选择如何受身份、资源和圈层规则塑造。 |
| 130 | PREP 表达模型 | Point、Reason、Example、Point，即观点、理由、例子、重申观点。 | 汇报和表达时先说结论，再给理由和例证。 |

## 与已安装 Skill 的对应关系

原资料的 150 个模型在已安装 Skill 中被压缩为 6 个可调用能力：

1. **战略情境诊断**：3C、PEST、SWOT。
2. **行业竞争与核心能力**：五力、价值链、核心竞争力。
3. **战略方向选择**：波特三战略、安索夫、波士顿矩阵。
4. **复杂问题拆解**：MECE、逻辑树、5W2H、5Why、5So、假设思考。
5. **不确定性决策**：OODA、矩阵思维、10/10/10。
6. **战略执行对齐**：7S、TOPIC、KPI 树、POA、PDCA。

其余模型仍保留在本目录中，作为完整模型索引；未全部作为独立触发入口，以避免 150 个入口造成调用混乱。
