# 决策规则速查 — 150个思维模型&麦肯锡战略思维分析工具

| 能力 | 一句话规则 |
|---|---|
| 战略情境诊断：3C、PEST 与 SWOT | 先把宏观环境、客户、竞争者和自身能力放在同一张图上，再形成可行动的战略假设。 |
| 行业竞争与核心能力：五力、价值链、VRIO式检查 | 判断利润空间来自哪里、被谁挤压，以及自身能力是否真的难以替代和模仿。 |
| 战略方向选择：竞争方式、产品市场与业务组合 | 在成本领先、差异化、聚焦，以及现有/新产品市场组合之间做出明确取舍。 |
| 复杂问题拆解：MECE、逻辑树、5Why、5So 与假设 | 把模糊问题拆成互斥且穷尽的分支，分别追问原因、后果和可验证假设。 |
| 不确定性决策：OODA、矩阵与时间尺度 | 在信息不完整时先观察和定位，再比较选项、明确时间尺度，并保留回滚和复盘信号。 |
| 战略执行对齐：7S、TOPIC、KPI 树、POA 与 PDCA | 把战略翻译成目标、责任、能力、流程、指标和反馈，让组织能持续执行和修正。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
