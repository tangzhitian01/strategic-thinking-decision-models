# 150个思维模型&麦肯锡战略思维分析工具 — 全书能力入口

## 触发与不触发

**适用**：与本书能力域相关的咨询与任务（见下方路由表的意图列）。
**不适用**：
- 没有具体问题和决策目标的泛泛模型介绍
- 仅凭模型替代法律、医疗、投资或审计专业意见
- 把案例中的数字和结论当作当前市场事实
- 只要执行清单但不需要战略判断的纯操作任务

## 核心原则（常驻速览，概览类问题读到这里即可回答）

1. 先定义决策问题、目标、时间范围和不可突破的约束，再选择模型。
2. 外部环境、客户、竞争者和自身能力必须同时进入战略诊断。
3. 模型输出必须导出取舍、假设、行动或指标，不能停留在分类和描述。
4. 动态环境优先采用 OODA，稳定且可规划的问题再用 PDCA。
5. 用多个互补模型交叉检查，但避免堆叠模型制造虚假精确。
6. 对每个结论写明证据、未知项、边界和下一次验证时间。

## 边界与判停

- 关键输入缺失且无法合理假设时，先列出缺口，不强行给出战略结论。
- 高风险决策缺少数据或专业审查时，只输出分析框架和待验证假设。
- 模型之间给出冲突方向时，保留冲突，回到目标、权重和证据检查。
